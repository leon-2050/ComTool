# 串口设备选择改进

串口设备改为明确的下拉列表，自动枚举系统已识别的端口并显示端口号及设备名称；可手动刷新，窗口可见时每 3 秒更新，恢复焦点时更新。未检测到的原选择保留并提示，不自动切换设备。连接中选择仍进入草稿，点击“应用并重连”生效。顶部冗余“连接配置”按钮已移除，Ctrl+, 仍定位配置区。

验证：前端构建通过、9 项单元测试通过、9 组界面回归通过；正式桌面包启动通过，使用内嵌资源且无开发测试入口；连接配置应用回归通过（TCP/UDP、历史保留、发送任务停止、草稿、失败处理和旧事件过滤）。本次串口桌面检查通过：下拉框可见、刷新完成、无设备提示、原 COM9 配置保留，页面无异常。

测试电脑枚举到 0 个真实串口。真实设备下拉选择、插拔更新、设备名称识别、两档波特率收发与端口释放仍需硬件验证。曾尝试模拟桌面 IPC 枚举，但运行时不支持该拦截方式，未将模拟结果计入通过项。

运行 ComTool/ComTool.exe。保持随附许可证文件。设备未出现时，确认接线与驱动，点击刷新。

# ComTool 0.1.1 Windows 安装版与绿色版

基于 main 的 7f9e862 及本次版本号/打包脚本更新生成，两种分发包使用同一个正式程序。保留 Rust Preview 标识，不表示全部硬件验收已完成。

- 安装版：ComTool-0.1.1-Windows-x64-setup.exe。当前用户安装，中英文向导，开始菜单和桌面快捷方式、系统卸载入口；缺少 WebView2 时尝试联网安装。
- 绿色版：ComTool-0.1.1-Windows-x64-portable.zip。解压运行 ComTool/ComTool.exe，需要系统已有 WebView2。
- 两版共用 %APPDATA%\ComToolRust\config.json；不属于配置随 U 盘移动的便携模式。更新前可导出配置；本版没有自动更新。
- 安装程序未做代码签名，Windows 可能显示未知发布者。
- 对应源代码一并提供 ComTool-0.1.1-source.zip，许可和依赖声明随包分发。

## 本次验证

17 项前端单元测试与生产构建通过，Rust/Tauri Release 构建通过。打包工具下载超时后，使用已缓存 NSIS 成功生成安装包。

实际隔离安装退出码 0；安装版程序与绿色版 SHA-256 一致，23 个许可文件齐全，程序版本与卸载项均为 0.1.1，桌面/开始菜单快捷方式目标正确。安装后正式桌面启动通过，页面使用内嵌资源且无开发入口；串口/TCP/UDP/SSH 模式、旧配置纠正和快捷键范围检查通过。

实际卸载退出码 0，程序、卸载项及测试快捷方式均移除。实际用户配置文件未改动，测试前已有的安装位置设置已恢复。测试未将本版留在系统中。

绿色版实际 TCP/UDP 应用重连回归通过：草稿、撤销、无效参数、保存失败、重复点击、历史保留、定时与文件发送停止、迟到事件、失败状态和原始记录保留。

测试机器已有 WebView2 155.0.4283.62。未验证缺少运行库时的联网引导安装、Win10 实机或真实串口硬件；其他尚未验收项继续见 rust-app/VALIDATION.md。本次未发布 GitHub Release。

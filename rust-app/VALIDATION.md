# Rust 预览版验证报告

日期：2026-10-14。平台：本机 Windows 11 x64，Rust 1.99.0 MSVC Release、Tauri 2、Node 22。对应源码为本预览版 Git 标签 `rust-v0.1.0-preview.1`。本报告记录实际完成的验证，不将虚拟测试视为硬件验证。

## 已通过

| 验证 | 结果与范围 |
|---|---|
| Rust Release 测试 | 6 项通过：TCP 完整字节/取消、UDP 报文边界、编码/HEX/转义、配置迁移与密码排除；网络使用真实本机套接字 |
| 前端测试 | 6 项通过：中文跨块、来源隔离、UDP 边界、8 MiB 与空报文块数上限、编码切换、高亮位置与原文保留 |
| 浏览器界面 | 5 组通过：100%/125%/150%/200% DPR、两种主题、900px 窄窗口、标签关闭按钮及 ANSI/256/RGB/中文夹具。DPR 模拟不等于真实多显示器切换 |
| 实际桌面 SSH | 本机 Paramiko 服务：密码、普通 RSA 私钥、带口令 OpenSSH 私钥、中文/ANSI 原始字节、输入回显、xterm-256color 和 PTY 尺寸同步；远端拒绝 PTY 时可见错误 |
| SSH 主机验证 | 首次确认保存；同一端点实际更换主机密钥后，在认证前拒绝连接 |
| 重连与取消 | TCP 自动重连保留原始记录，两段不完整 UTF-8 不被拼成另一次连接的字符；SSH 握手取消约 60ms |
| TCP 服务端 | 两个真实客户端：定向发送隔离、广播、来源索引、断开指定客户端 |
| UDP 桌面互通 | 发送字节正确，接收索引报文长度 2、1、0，空报文保留 |
| 文件/定时发送 | 1 MiB 二进制文件回环校验一致，停止定时后不再增加发送计数 |
| 持续接收 | 8 个连接存在，主连接以 0.99998 MiB/s 接收 600.01 秒，共 629145617 字节（含初始 17 字节）；发送数据与原始记录 SHA-256 一致，丢弃计数为 0 |
| 最终版并行回归 | 8 个会话均持续接收 60 秒，逐个原始记录校验一致；主连接约 1 MiB/s，其余各约 4 KiB/s；无界面脚本异常 |
| 安装/启动/卸载 | NSIS 静默安装到隔离工作目录、实际程序启动、23 个许可文件、卸载均通过。测试机器已安装 WebView2 |

10 分钟压力记录 SHA-256：`5b1d17251b127164ca361967c85538b9e21854a00464449f68dc8d082b097588`。压力时自动点击主题切换，点击完成耗时约 40–209ms；这含自动化开销，不是通信延迟指标。该长测发生在最终重连边界修复前，最终程序另做 60 秒并行回归。

## 启动与资源对比

每版先启动一次新配置，再在同一配置下重复启动 20 次。均为真实桌面窗口、浅色、一个默认断开的串口收发会话。没有运行编译或压力测试。计时由启动进程到界面就绪标记；Python 标记包含 50ms 延迟，Rust 在前端初始化后报告，轮询精度 10ms。此处不是系统重启后的冷启动，也不能代表所有会话布局。

| 指标（20 次） | Python 版 | Rust 版 |
|---|---:|---:|
| 启动中位数 | 1.530s | 0.559s |
| 启动 P95 | 1.906s | 0.634s |
| 进程树工作集总和中位数 | 99.0 MiB | 462.0 MiB |
| 进程树私有内存中位数 | 63.6 MiB | 276.9 MiB |
| 就绪后 0.5s CPU 中位数（单核百分比） | 3.125% | 4.688% |
| 进程数量 | 1 | 7 |

本场景启动缩短 63.5%，达到中位数 ≤2s 且降低至少 30% 的目标。Rust/WebView2 的总内存与启动 CPU 成本更高，不能据此声称所有资源表现更好。工作集总和会重复计入共享页，因此同时报告私有内存；CPU 采样很短，不是长期空闲指标。原始 20 次结果见 `validation/startup-report.json`。

## 交付与尚未验收

提供 NSIS 安装包、免安装 ZIP、源码 ZIP、构建脚本与依赖通知。免安装版依赖已安装 WebView2；安装包配置下载引导，缺失运行库的实际安装路径尚未在无运行库机器测试。安装包不包含完整 WebView2 Runtime，因此应用包体积不能算运行库总体积。

当前机器扫描到 0 个串口，真实串口收发、拔插、Mark/Space、1.5 停止位和 DSR/DTR 驱动兼容性未验收；Windows 10 实机、真实多显示器 DPI 切换、中文 IME 交互、系统剪贴板、vim/top 等远端完整程序和磁盘满场景也未现场验证。xterm 引擎提供相应能力，但不能代替这些验收。OpenSSH 加密私钥已验证；某些旧式加密 PEM 格式不兼容时会提示转换格式。

协议脚本、图表、外部 Python 插件和分离窗口仍使用 Python 版。本次以 Rust 预览版发布，不替换 Python 主版本。后续主版本需补齐以上验收并继续优化进程树内存。

# ComTool 通信工作台

基于 [Neutree/COMTool](https://github.com/Neutree/COMTool) 的 master 分支，基准提交：
`8dbf97d6502f33e51be60401f738c7ff6442eb9e`，上游版本 3.4.1。

## 界面变化

- 以数据为中心重新组织工作台，统一浅色/深色主题、靛蓝主要操作、字体与控件。
- 顶部显示当前会话、连接类型、端口/目标信息和连接状态；可直接连接或断开。
- 左侧常驻会话列表，可搜索、切换、新建或收起；中央数据区获得更大的宽度。
- 右侧参数与工具共用单个抽屉，默认收起，不同时堆叠多个侧栏。
- 参数面板将连接参数与收发选项分成标签页；顶部为统一连接/断开入口。
- 接收监视与发送编辑独立成块，浅色模式日志采用浅色背景。
- 文本/HEX 分段按钮直接位于收发区，和原设置页双向同步。
- 接收区为空时显示居中提示，连接状态改变时更新；有数据时自动隐藏，清空后恢复。
- 未连接时禁用发送按钮；已连接时启用，并保留 Ctrl+Enter 发送快捷键。
- 接收区只读，支持选择复制和一键复制全部内容；发送区增加清空按钮。
- 发送历史采用紧凑选择器，空时有用途提示，长内容可通过悬浮提示查看。
- 右侧工具区保留日志、发送文件和自定义发送等功能；配置导入/导出移至会话菜单。
- 标题栏外观按钮可一键切换浅色/深色；菜单保留外部插件文件加载、语言和帮助入口。
- 窄窗口打开抽屉或打开后缩窗时自动收起左侧栏，关闭抽屉后恢复。
- 分离窗口保留连接参数，并增加独立的设置/工具入口；恢复标签后重新同步面板。
- 默认窗口 1280×840，适配屏幕可用尺寸，状态栏固定高度，数据区优先伸展。
- 全新配置默认使用简体中文；已有配置仍沿用保存的语言、主题等设置。
- 应用显示名称统一为 `ComTool`，包括标题栏、系统窗口名称和关于页面；可执行文件为 `ComTool.exe`，沿用原配置目录与保存的会话。
- 修正发送设置中“转义符”控件重复添加且与“记录”控件重叠的问题。
- 修复全部会话分离后空窗口的关闭/键盘事件，以及关闭会话后切换主题的按钮销毁问题。
- 修复终端文字在高 DPI 屏幕发虚：缓存按实际像素密度绘制并标注 DPR，保持字体字号和终端逻辑行列不变。
- 终端位图绘制移到 GUI 线程；接收线程保留终端解析，避免边接收边绘制位图。
- SSH 会话声明为 `xterm-256color`，让根据终端类型选择颜色的远端程序获得正确的颜色能力信息；重新连接后生效。
- 终端补全 ANSI 基本色、亮色、256 色与 RGB 前景/背景色，以及粗体、斜体、下划线、删除线和反显。
- 终端默认开启关键词高亮，为普通文本中的 IP 地址、命令参数和错误/状态关键词着色；命令自带颜色优先，全屏应用期间暂停关键词高亮。
- 可在终端的“连接配置 → 选项”中关闭“关键词高亮”，保留命令自带颜色。高亮只改变显示，不改变输出内容、发送数据或复制文本。
- 终端文字、光标和选区按字符网格定位；选区使用显示覆盖层，取消选择时保留原 ANSI 背景色。
- 移除启动 Logo 闪屏，完成界面初始化后直接显示主窗口。
- 正常运行关闭调试输出，不再逐条写启动日志；出现错误时仍记录诊断信息。
- 内置插件按需加载。全新配置只打开收发页，协议、终端、图表可从左侧“＋”添加；已有会话按配置完整恢复。
- 自动更新检查延后到主窗口显示 5 秒后进行，网络请求设置超时。
- 程序文件与任务栏采用“会话连接”图标：深蓝底、白色终端提示符与青色会话轮廓，体现串口、SSH 和网络通信调试。Windows 图标包含 16–256 像素七种尺寸，16 像素版本适当简化并加粗。
- 标题栏使用 20 像素、无底色的“会话连接”线稿，按浅色/深色主题着色，保持左侧留白与垂直居中，帮助窗口也使用相同处理。
- 常用操作、会话列表及窗口控制统一为圆角线条图标，统一线宽、视觉尺寸和按钮间距；按屏幕像素密度绘制。
- 去掉标题栏图标按钮的独立底色，复制/清空等按钮统一尺寸；选中会话图标跟随强调色，禁用发送图标保持清晰可辨。
- 会话标签的关闭 X 默认隐藏，鼠标移入标签后显示 8 像素的细线 X；点击区域保持 18×18，显隐时标签宽度和位置不变。
- 平衡会话标签两侧的留白，修正隐藏关闭按钮后文字偏左的问题；默认与悬停状态下文字保持居中。

保留上游串口、TCP/UDP、SSH 通信实现及收发、协议、终端和图表插件。

## Windows 运行

解压完整的 Windows 压缩包，双击 `ComTool/ComTool.exe`。
请保留同目录下的 `_internal` 文件夹，它包含程序运行所需的 Qt 和 Python 库。
无需另外安装 Python。

可将新版解压到独立文件夹运行，使用原有的个人配置。任务栏若固定了旧路径，请改用新版程序的快捷方式。
如需诊断启动问题，可在解压后的目录临时运行：

```powershell
$env:COMTOOL_DEBUG = "1"
.\ComTool\ComTool.exe
Remove-Item Env:\COMTOOL_DEBUG
```

诊断日志位置为 `%APPDATA%\COMTool\run.log`。正常启动不会新增日志文件，旧日志不会自动删除。
这里的应用诊断日志与工具面板的通信数据记录功能独立，通信记录功能仍可使用。

## 从源码运行或重新打包

本次构建环境为 Windows x64、Python 3.12.14、PyQt5 5.15.11、PyInstaller 6.22.3。
完整依赖版本见 `requirements-windows-build.txt`。

在源码仓库根目录执行（`python` 应指向 Python 3.12 x64）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-windows-build.txt
.\.venv\Scripts\python.exe COMTool\Main.py
```

打包成可执行程序：

```powershell
.\tool\build_windows.ps1 -Python (Resolve-Path .\.venv\Scripts\python.exe).Path
```

默认输出 `dist/ComTool/ComTool.exe`。也可传入 `-OutputDirectory` 指定输出目录。
脚本先编译翻译资源，再使用 PyInstaller 打包主题、图标、语言和协议资源。

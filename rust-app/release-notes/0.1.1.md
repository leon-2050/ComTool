# ComTool Rust 0.1.1 预览版（Windows x64，未签名）

- 连接配置常驻右侧，连接中编辑草稿，通过“应用并重连”生效；保留接收历史并重新初始化 SSH 终端。
- 串口设备自动枚举并提供下拉选择；串口/TCP/UDP 使用收发界面，SSH 使用交互终端。
- 提供当前用户安装的 NSIS 安装包和解压运行的绿色版，两版功能相同。
- 安装版和绿色版共用 `%APPDATA%\ComToolRust\config.json`，升级前可导出配置备份。

## 下载

- `ComTool-0.1.1-Windows-x64-setup.exe`：安装版，包含开始菜单、桌面快捷方式和卸载入口。
- `ComTool-0.1.1-Windows-x64-portable.zip`：绿色版，解压后运行 `ComTool/ComTool.exe`。
- `ComTool-0.1.1-source.zip`：本次构建对应的完整仓库源码，保留上游来源与许可。
- `SHA256SUMS.txt`、`build-manifest.json`：文件校验值及构建来源。

绿色版需要系统已有 Microsoft Edge WebView2 Runtime；安装版在缺失时尝试联网安装。未配置自动更新。

## 验证与边界

本机 Windows 11 的安装、启动、卸载及 TCP/UDP 应用重连回归通过。GitHub Actions 构建必须通过前端和 Rust 单元测试、实际安装/卸载、桌面连接模式及 TCP/UDP 重连检查后才会发布。

真实串口设备的波特率切换、收发、拔插和特殊流控，Win10 实机、无 WebView2 环境、中文输入法/剪贴板、真实跨屏缩放、完整 SSH 远端程序以及磁盘满仍待验收。自动化测试不能替代这些现场验证，详见 [VALIDATION.md](https://github.com/leon-2050/ComTool/blob/main/rust-app/VALIDATION.md)。

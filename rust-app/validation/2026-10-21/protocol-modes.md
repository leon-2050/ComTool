# 连接类型与界面模式修正（2026-10-21）

| 连接类型 | 界面 | 支持的工作模式 |
|---|---|---|
| 串口 | 收发（文本/HEX） | 串口设备 |
| TCP | 收发（文本/HEX） | 客户端、服务端 |
| UDP | 收发（文本/HEX） | 发送/接收、绑定监听 |
| SSH | 交互终端 | SSH 客户端 |

删除所有连接类型上的通用“收发/终端”切换。加载旧配置、导入配置及修改连接类型时统一修正界面模式，避免旧的 view 字段造成错误界面。连接中修改连接类型时，当前界面仍跟随实际会话，应用后才切换。

SSH 隐藏接收时间戳、收发换行/转义设置；其他类型隐藏终端关键词高亮。SSH 不显示本地绑定参数与服务端模式。通信记录、编码、字号等适用设置保留。

前端构建通过。17 项单元测试通过（包含 8 项连接类型与旧模式修正用例）；6 种协议/工作模式组合界面检查通过；9 组主题、窗口尺寸、配置草稿回归通过。浏览器检查不代表真实协议收发；真实串口硬件仍未验证。

正式桌面程序验证通过：四类连接的错误旧模式均纠正并保存，模式切换按钮不存在，Ctrl+Enter 只在收发界面触发，SSH 终端正常挂载；正式包使用内嵌资源且未包含开发测试入口。TCP/UDP 应用重连、历史保留、草稿隔离、停止发送任务及失败处理回归通过。
